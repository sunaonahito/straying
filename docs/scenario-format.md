# Scenario Format

## 基本方針

シナリオは物語を書くことに集中できるようにする。

ログ取得やデータ送信はRNFが担当する。

---

# 質問

すべての質問には questionId を付与する。

例

Q001
Q002
Q003

---

# 選択肢

すべての選択肢には choiceId を付与する。

例

A
B
C

または

C001
C002
C003

---

# 自由入力

自由入力には inputId を付与する。

例

I001

---

# シーン

すべてのシーンには sceneId を付与する。

例

intro

chapter01

ending_good

ending_bad
