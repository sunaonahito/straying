# Straying

Research Novel Framework（RNF）を使用して開発中のストーリー型対話教材プロトタイプです。

## Current Version

Playtest build for September 2026.

## How to Run

1. リポジトリをダウンロードまたはCloneします。
2. `tyrano` フォルダ内のプロジェクトをTyranoScript / TyranoStudio環境で起動してください。
3. ゲーム開始後、タイトル画面からプレイできます。

## Notes

- 現在開発中のプロトタイプです。
- シナリオ、UI、画像素材等は今後変更される可能性があります。
- 一部、開発・検証用ファイルを含んでいます。
- Research Novel Framework（RNF）によるプレイログ・回答ログ取得機能を含みます。

## Repository Structure

- `tyrano/` : ゲーム本体
- `scripts/` : RNF関連スクリプト・設定
- `assets/` : 開発用素材
- `apps-script/` : Google Apps Script関連
- `docs/` : ドキュメント
- `design/` : デザイン関連データ
